# Week 3 – Password Cracking with John the Ripper

## Project Overview

As part of my **Network Walks Cybersecurity Internship – Week 3**, I completed a practical exercise on password security and password recovery using **John the Ripper**.

The main objective of this project was to understand how password hashes work, how password-protected PDF files can be assessed in an authorised lab environment, and how dictionary-based password testing works.

This hands-on exercise helped me understand the importance of choosing strong passwords and how easily weak or commonly used passwords can be discovered.

## Objectives

- Understand the basics of password hashing.
- Learn how to extract a password hash from a protected PDF.
- Explore John the Ripper and its graphical interface, Johnny.
- Understand dictionary-based password testing.
- Observe how a matching password is identified.
- Verify the recovered password by opening the protected PDF.

## Tools Used

| Tool | Purpose |
|---|---|
| John the Ripper | Password-hash testing and recovery |
| Johnny | Graphical interface for John the Ripper |
| Network Walks Hash Calculator | Extracting the PDF password hash |
| Network Walks Dictionary Attack Lab | Understanding dictionary-based password testing |
| Password-protected PDF | Sample file used for the exercise |

## Methodology

### 1. Environment Setup
Installed and configured John the Ripper on Windows. Opened Johnny and checked whether the John the Ripper executable was detected correctly.

### 2. PDF Hash Extraction
Used the Network Walks Hash Calculator to extract the password hash from the company-provided protected PDF.

### 3. Loading the Hash
Loaded the extracted hash into Johnny and checked that the PDF hash was recognised.

### 4. Dictionary-Based Password Testing
Observed the dictionary-based password-testing process in the authorised Network Walks lab. The exercise demonstrated how candidate passwords are checked against a password hash.

### 5. Password Recovery and Verification
Observed successful password recovery in the lab and verified access to the protected PDF using the recovered password.

### 6. Completion Evidence
Captured screenshots showing the tool configuration, hash extraction, password recovery, and successful PDF access.

## Results and Findings

The project was completed successfully in the provided lab environment.

Through this exercise, I learned that:

- Password hashes are used to verify passwords without storing them as plain text.
- Weak and commonly used passwords can be vulnerable to dictionary-based guessing.
- John the Ripper can be used to assess password strength in authorised testing environments.
- A password-protected file should use a strong, unique password.
- Password security is an important part of protecting sensitive information.
